Markup

Applied to every cost DevChat reports, on top of the ckey.vn list price. It changes what the dashboard and the calculator show — it never changes what the provider charges a user's own key.

 

Administrator protection

Sign-in locks are stored in the database, so they survive a restart. Administrators lock after fewer wrong tries than normal users, sign-in sessions last shorter, and changing an account or a role asks for the admin password again. Nothing here locks you out for good: npm run admin -- --unlock <name> clears any lock, and npm run admin -- --reset <name> sets a new password.
